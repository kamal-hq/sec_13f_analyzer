# Power BI Dashboard (`dashboard/`)

`dashboard/data/` contains tracked CSV snapshots exported by `run_pipeline.py` (`convergence_signals.csv`, `discretionary_signals.csv`, `new_positions_signals.csv`, `top_holdings.csv`, `fund_aum.csv`, `fund_summary.csv`, and `sector_by_period.csv`) for Power BI reporting (see `output/data_dictionary.md` for full column definitions).
